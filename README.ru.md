# T-DuoBar

Наш форк [DuoBar от Mikeli7666](https://github.com/Mikeli7666/DuoBar): компактный индикатор в строке меню macOS с расширенной информацией о батарее, сети и аудиоустройствах.

[English](README.md) · [Разработка и локальная установка](DEVELOPMENT.md)

## Установка и обновление через Homebrew

```sh
brew install --cask squazaryu/tap/t-duobar
brew update
brew upgrade --cask squazaryu/tap/t-duobar
```

Перед первой установкой через Homebrew завершите установленный вручную DuoBar и сохраните `/Applications/DuoBar.app`. `--adopt` подходит только для идентичной копии; не используйте `--force`, чтобы потерять старую установку.

С 1.6.0 приложение проверяет опубликованную версию Homebrew раз в неделю, пока запущено, и догоняет пропущенную проверку после запуска или пробуждения Mac. О новой версии приходит одно уведомление, если разрешено macOS. Кнопка **«Установить через Homebrew»** открывает Terminal с подготовленным скриптом: он обновляет приложение и запускает его снова. Установка происходит только после нажатия. Если Homebrew отсутствует, выводится инструкция; менеджер пакетов автоматически не устанавливается.

В «Настройки → Обновления» есть переключатель недельных проверок, ручная проверка, установка, release notes и команда обновления. При закрытом приложении проверки не идут. После сетевой ошибки повтор выполняется через шесть часов.

С версии 1.6.1 настройки всегда показывают установленную версию и номер сборки. После каждой ручной проверки появляется окно: установленная и доступная версии с кнопкой установки, подтверждение актуальности установленной версии или ошибка соединения. Еженедельное уведомление об обновлении также содержит установленную и доступную версии. Для окон ручной проверки разрешение на системные уведомления не требуется.

### Изменения 1.11.0, сборка 29

- Отдельная карточка VPN: сообщаемое macOS состояние и название профиля, дополнительные сведения об интерфейсе и переход в системные настройки. Раздел можно скрыть или переставить независимо от сети.
- Выбор классического оформления или нативного Liquid Glass. Стекло доступно в macOS 26+, имеет настройку прозрачности фона и сохраняет обычную непрозрачность текста и элементов управления. По умолчанию включено классическое оформление; оно также используется на старых macOS и при «Уменьшить прозрачность».
- Кнопка «Предпросмотр меню» в настройках открывает настоящий pop-up. Оба оформления используют один контент и состояние раскрытых разделов.
- Обычное нажатие по значку переключает меню один раз при начале клика; отпускание кнопки не открывает его повторно. Контекстное меню и режим наведения сохранены.
- Наблюдение VPN работает при видимом меню, сохраняет последнее состояние при обновлении, объединяет события и отклоняет отменённые или запоздалые ответы.

Несовместимых изменений и миграций нет. Прежние настройки сохраняются; в старый порядок разделов VPN добавляется рядом с сетью.

### Предыдущие улучшения (1.10.0)

- Выбор языка в разделе «Внешний вид»: язык системы, английский, русский, украинский, упрощённый или традиционный китайский. Надписи интерфейса обновляются без перезапуска.
- Можно скрыть пустой раздел аксессуаров. Подключённые устройства появляются автоматически; ошибки чтения остаются видны.
- Можно менять громкость прокруткой по значку в строке меню. Оба новых переключателя поведения по умолчанию выключены.
- Проценты батареи и громкости расположены рядом с названиями и используют одинаковую типографику. Слайдер занимает доступную ширину строки.
- Нажатие на пустое место между текстом раздела и стрелкой теперь раскрывает и закрывает подробности. Переход в системные настройки работает отдельно.

Несовместимых изменений и миграций нет. Прежние настройки сохраняются.

### Предыдущие улучшения (1.9.0)

- Вкладки настроек «Основные», «Уведомления» и «Обновления». Правый клик по значку открывает настройки, проверку обновлений и выход.
- Порядок шести разделов pop-up меняется перетаскиванием или командами «Выше/ниже» и сохраняется отдельно от их видимости.

- Быстрые переходы в системные настройки и пояснения для недоступных данных сети, батареи, звука и аксессуаров.
- Значок «цепочка» для Wi-Fi, который macOS помечает как затратное соединение. Ограничение определения точки доступа описано ниже.
- Собственная иконка T-DuoBar и окно «О приложении» с версией, сборкой и ссылками на проект.
- Чтение аксессуаров отменяется при закрытии pop-up; запоздалый результат не перезаписывает свежие данные. Таймеры допускают объединение пробуждений системой.
- Кнопки находятся внутри карточек, пустой блок аксессуаров стал компактным, молния не пересекает кольцо, заголовок не смещается при раскрытии подробностей.

### Остальные возможности

- Время до разрядки или полного заряда в разделе батареи pop-up меню.
- Подробности питания и мощность адаптера.
- Заряд подключённых аксессуаров, включая отдельные показания AirPods и кейса, если macOS их предоставляет. Старые показания отключённых устройств исключены.
- Сигнал Wi-Fi, диапазон, канал и локальный IPv4-адрес с копированием.
- Выбор аудиовыхода, сохранение избранных устройств и отдельный выбор микрофона.
- Однократное уведомление при пересечении порога 10%, 20% или 30%. По умолчанию выключено; включение требует системного разрешения.
- Настройка состава меню и отображения оставшегося времени. Для длинного раскрытого меню предусмотрена прокрутка.
- Сохранены кольцо батареи, управление громкостью и цветовая индикация оригинального DuoBar.

## Сборка и установка

Нужны macOS 13+ и полный Xcode. Сборка и тесты проверены на Apple Silicon; все версии macOS и аксессуары физически не проверялись.

```sh
git clone https://github.com/squazaryu/T-DuoBar.git
cd T-DuoBar
./script/build_and_run.sh --verify
```

Скрипт собирает Release, проверяет локальную подпись, устанавливает `/Applications/DuoBar.app` и проверяет путь запущенного процесса. Предыдущая копия сохраняется в `~/Library/Application Support/T-DuoBar/Backups/`.

**Сборки этого форка с Developer ID и notarization пока нет.** Экспериментальный DMG и локальная сборка имеют ad-hoc подпись. Отображаемое имя — T-DuoBar; имя файла `DuoBar.app` и bundle identifier сохранены. Используются прежние настройки, установленный DuoBar заменяется, одновременный запуск форка и оригинала не предусмотрен.

## Проверка и ограничения

Версия 1.11.0 прошла 352 теста; шесть аппаратных проверок пропущены. Release собран для Apple Silicon и Intel, проверки запуска выполнялись на Apple Silicon. Нативные тесты проверяют настоящий контроллер меню, стеклянную поверхность, прозрачность подложки, очистку наблюдателей и повторные клики. Короткие замеры и границы проверки описаны в [отчёте производительности и жизненного цикла](release/1.11.0/VALIDATION.md). Это не подтверждение отсутствия любых утечек, расхода энергии за длительный период или совместимости со всем оборудованием.

- VPN определяется по настроенным подключениям, о которых сообщает macOS; имя туннеля само по себе не доказывает VPN. Приложение не утверждает, что весь трафик идёт через него, и не включает/отключает соединение.
- Оценка времени берётся из macOS и может быть недоступна.
- Показания аксессуаров зависят от системного отчёта Bluetooth. Чтение выполняется локально, пока открыт соответствующий блок меню.
- Достоверный публичный источник лимита заряда пока не найден: поле отображает «Недоступно». Лимит не угадывается по заряду 80% или приостановленной зарядке.
- Мощность адаптера — сообщаемый номинал, а не измерение текущей мощности зарядки.
- Данные Wi-Fi могут быть скрыты macOS; некоторые аудиоустройства не поддерживают программное управление громкостью.
- Значок точки доступа выбирается по системному признаку затратного Wi-Fi, а не по модели устройства. Телефон без этой метки сохраняет обычный значок Wi-Fi; другая сеть с тарификацией трафика может получить «цепочку». Название сети не используется для угадывания, соседние сети не сканируются.
- Уведомление появляется при пересечении порога, а не сразу при запуске с низким зарядом.

Нет аналитики и передачи системных показаний. Проверка обновлений выполняет HTTPS-запрос к файлу версии нашего Homebrew tap; данные батареи, сети и устройств не передаются. Выбор микрофона меняет устройство ввода Core Audio; приложение не записывает звук.
