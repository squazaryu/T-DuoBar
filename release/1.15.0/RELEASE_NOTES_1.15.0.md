# T-DuoBar 1.15.0 · build 42

All three options start off and can be enabled independently in **Settings → General**.

- **Live network traffic** shows local receive and send rates for the active interface in expanded Network. Sampling pauses on collapse, pop-up close and display sleep. The next session starts with a fresh baseline.
- **Battery health** shows cycle count and estimated maximum capacity in expanded Battery. The app reads the internal battery on demand. The estimate can differ from the value in macOS.
- **Desktop status indicator** shows the battery ring, network symbol and volume dots in three sizes. Drag it to a new position to save the placement for that screen.

## Compatibility and upgrade

Universal 2 for macOS 13 and later. This experimental community build uses an ad-hoc signature. Existing preferences and battery history keep their format. Update through Homebrew or download the DMG and use the included installation instructions.

Три новые опции в **Настройки → Основные** выключены по умолчанию.

- **Текущий трафик** показывает скорости приёма и отправки в раскрытой «Сети». Замеры останавливаются при сворачивании раздела, закрытии меню и сне дисплея.
- **Состояние аккумулятора** показывает число циклов и оценку максимальной ёмкости. Она может отличаться от значения в macOS.
- **Индикатор на рабочем столе** показывает заряд, сеть и громкость. У него три размера. Приложение запоминает положение индикатора на выбранном экране.

Сборка для Apple Silicon и Intel, macOS 13 и новее. Прежние настройки и история батареи сохраняются при обычном обновлении. Выпуск экспериментальный, с ad-hoc подписью.
